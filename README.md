# Minecraft GUI Texture: WorldMenuSkin

WorldMenuSkin is a 16×16 Minecraft GUI texture asset: a pixel-art world menu button with a dark frame and a green land pattern on a blue background. It is provided as an SVG source file for use in projects that support custom GUI textures.

## Install

1. Download or clone the project.
2. Find `assets/gui/world_menu_button.svg`.
3. If your Minecraft resource pack or GUI system requires PNG textures, open the SVG in an image editor or convert it with an SVG-capable tool, keeping the output at 16×16 pixels.
4. Add the SVG or converted PNG to the texture location expected by your resource pack, mod, or GUI project. Minecraft does not automatically load this asset from the provided path.

## Use

1. Open the texture in an SVG-compatible editor to inspect or edit it, or use the converted PNG in your project.
2. Configure your resource pack, mod, or GUI implementation to load the texture as a world menu button.
3. Test it in the target interface and adjust the integration or scaling settings if needed.
